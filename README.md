# Gestion de Cantine Scolaire — projet APK Android

Projet Android natif (Activity Java + WebView locale) intégrant les 7 modules de gestion.
Le contenu fonctionne hors connexion et conserve les données localement sur le téléphone.

## Construire l'APK avec GitHub depuis un téléphone
1. Créer un dépôt GitHub public ou privé.
2. Ajouter tous les fichiers et dossiers de ce projet à la racine du dépôt.
3. Ouvrir l'onglet **Actions** du dépôt.
4. Sélectionner **Construire APK Android** puis **Run workflow** (ou attendre le lancement après push).
5. Ouvrir l'exécution terminée, descendre à **Artifacts** et télécharger `Gestion-de-Cantine-APK`.
6. Extraire le ZIP téléchargé puis installer `app-debug.apk`. Android peut demander d'autoriser Chrome/GitHub à installer des applications inconnues.

Nom de l'application : GESTION DE CANTINE SCOLAIRE
Prix initial d'une ration : 25 F CFA.

Les données sont conservées sur l'appareil. Exporter régulièrement les sauvegardes depuis Paramètres.
